QUESTION

Basic HTML Structure

Create an HTML webpage according to the following requirements.

Requirements

  1. Set the page title as Test1.
  2. Display 25CS208 Web Technology as the main heading.
  3. Display Module 1 and HTML as subsequent headings.
  4. Create a 5-line paragraph with at least two line breaks.
  5. Encapsulate the main content inside a div.
  6. Place an hr at the beginning and ending of main.
  7. Create an ordered list with 5 items using reversed Roman numerals.
  8. Create an unordered list with 5 items.
  9. Create a description list with 3 terms and descriptions.
  10. Create a 3-row and 4-column table.
  11. Merge the first-column cells of rows 1 and 2.
  12. Merge the first three columns of the last row.
  13. Apply a background color and text color to the body.

Table Numbering

Number the table cells consecutively from the top-left, taking merged cells into account.
